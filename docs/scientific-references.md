# Scientific References

A curated list of key publications underpinning the data in this project.
All claims in `data/` (English scientific reference documents) should link back to one or more of these.

Every DOI on this page resolves on Crossref and matches the author and title
stated beside it. Run `python scripts/check_dois.py` to re-verify the whole
repository; it fails when a DOI is dead or points at a different paper.

Last updated: 29 August 2026 — aligned with the review dates of the two
reference documents in [`data/`](../data/README.md).
